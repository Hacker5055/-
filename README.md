# كيف يعمل نظام التشغيل؟ — موشن جرافيك تفاعلي 🎬

تجربة موشن جرافيك تعليمية متكاملة (HTML + CSS + SVG + GSAP) تشرح عمل نظام التشغيل
ودوره في إدارة موارد الكمبيوتر: من لحظة الإقلاع (BIOS/UEFI وتحميل النواة)،
إلى استعارة «قائد حركة المرور» في مدينة رقمية، وإدارة المعالج والذاكرة والتخزين والتعريفات،
وختامًا بمثال كامل: تنفيذ أمر طباعة من النقرة حتى خروج الورقة.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:
```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## الملفات
- `index.html` — التطبيق الكامل في ملف واحد: المسرح المتحرك (SVG)، خط GSAP الزمني الرئيسي،
  أزرار التحكم، مختبر الصوت والمزامنة، لوحة المشاهد، وجدول المزامنة.
- `STORYBOARD.md` — لوحة القصة الكاملة: لكل مشهد (النص الصوتي / الوصف البصري / نوع الحركة / التوقيت).

## مزامنة الصوت
1. **رفع ملف صوتي محلي** (الأدق): من «مختبر الصوت» — تُضبط الحركة تلقائيًا على مدة التسجيل.
2. **Google Drive**: زر «محاولة التشغيل من Drive» (قد تمنعه قيود Drive على البث المباشر).
3. **النطق الآلي (TTS)**: يقرأ المتصفح نصوص المشاهد بالعربية دون أي ملف.
4. **بدون صوت**: الخط الزمني يعمل منفردًا مع تعليقات نصية لكل مشهد.

> النصوص الحالية مُعاد بناؤها تعليميًا بنفس محور التسجيل الأصلي؛ للمطابقة الحرفية
> عدّل قيم `vo` و`dur` داخل مصفوفة `SCENES` في `index.html`.
